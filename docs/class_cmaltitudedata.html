CMAltitudeData¶

Inherits: RefCounted < Object

A relative altitude / barometric pressure sample from CMAltimeter.

Description¶

Wraps Apple’s CMAltitudeData. The altitude is reported relative to the point at which updates were started, not absolute sea level — for absolute readings, use CMAltimeter.start_absolute_altitude_updates() and CMAbsoluteAltitudeData.

See Apple’s CMAltitudeData reference.
