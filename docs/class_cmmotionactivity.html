CMMotionActivity¶

Inherits: RefCounted < Object

A user-activity classification (walking, running, automotive, etc.) from the system motion coprocessor.

Description¶

Wraps Apple’s CMMotionActivity. More than one activity flag may be set simultaneously (e.g. walking and automotive when the user is moving inside a vehicle). The system uses confidence to indicate how certain the classification is.

See Apple’s CMMotionActivity reference.
