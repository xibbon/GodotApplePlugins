GKLeaderboardSet¶

Inherits: RefCounted < Object

Represents a Game Center leaderboard set.

Description¶

GKLeaderboardSet groups related leaderboards in Game Center. Use load_leaderboard_sets() to fetch available sets, then load_leaderboards() to enumerate the boards inside a set.
