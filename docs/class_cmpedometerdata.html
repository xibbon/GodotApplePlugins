CMPedometerData¶

Inherits: RefCounted < Object

Aggregated pedometer data covering a time window.

Description¶

Wraps Apple’s CMPedometerData. Optional Apple values (distance, floor counts, pace, cadence) report -1 when the underlying capability is unavailable on the device. See Apple’s CMPedometerData reference.
