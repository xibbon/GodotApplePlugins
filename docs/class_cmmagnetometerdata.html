CMMagnetometerData¶

Inherits: RefCounted < Object

A single magnetometer sample produced by CMMotionManager.

Description¶

Wraps Apple’s CMMagnetometerData. Provides the raw magnetic field reading in microteslas along each device axis. Includes bias from device magnetic interference. For a bias-corrected value, use device-motion updates and read CMDeviceMotion.magnetic_field instead. See Apple’s CMMagnetometerData reference.
