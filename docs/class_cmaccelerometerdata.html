CMAccelerometerData¶

Inherits: RefCounted < Object

A single accelerometer sample produced by CMMotionManager.

Description¶

Wraps Apple’s CMAccelerometerData. Provides the raw accelerometer reading in G-forces (1 G = 9.81 m/s²) along each device axis. See Apple’s CMAccelerometerData reference.

Property Descriptions¶

Vector3 acceleration 🔗

  • void set_acceleration(value: Vector3)

  • Vector3 get_acceleration()

Acceleration along each axis in G-forces. Includes gravity. To remove gravity, use device-motion updates and read CMDeviceMotion.user_acceleration instead.

float timestamp 🔗

  • void set_timestamp(value: float)

  • float get_timestamp()

The time at which the sample was taken, in seconds since device boot.
