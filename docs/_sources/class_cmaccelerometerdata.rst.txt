CMAccelerometerData
===================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A single accelerometer sample produced by :ref:`CMMotionManager<class_CMMotionManager>`.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMAccelerometerData``. Provides the raw accelerometer reading in G-forces (1 G = 9.81 m/s²) along each device axis. See Apple's `CMAccelerometerData reference <https://developer.apple.com/documentation/coremotion/cmaccelerometerdata>`__.
