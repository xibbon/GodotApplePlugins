CMMotionActivityManager
=======================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Classifies the user's current activity (walking, running, automotive, cycling, stationary).

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMMotionActivityManager``. The system continuously classifies user activity in the background while motion permission is granted, so :ref:`query_activity()<class_CMMotionActivityManager_method_query_activity>` can return historical data even from before your app launched.

\ **Requires the ``NSMotionUsageDescription`` Info.plist key.**\ 

\ **Platform availability:** Real implementation on **iOS**. On other platforms :ref:`is_activity_available()<class_CMMotionActivityManager_method_is_activity_available>` returns ``false`` and calls report unavailability via the callback or :ref:`activity_failed<class_CMMotionActivityManager_signal_activity_failed>`.

See Apple's `CMMotionActivityManager reference <https://developer.apple.com/documentation/coremotion/cmmotionactivitymanager>`__.
