CMAltimeter
===========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Reports relative and (iOS 15+) absolute altitude from the device barometer.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMAltimeter``. Use :ref:`start_relative_altitude_updates()<class_CMAltimeter_method_start_relative_altitude_updates>` for change-from-start readings and :ref:`start_absolute_altitude_updates()<class_CMAltimeter_method_start_absolute_altitude_updates>` for sea-level-referenced readings (iOS 15+).

\ **Requires the ``NSMotionUsageDescription`` Info.plist key.**\ 

\ **Platform availability:** Real implementation on **iOS**. On other platforms ``is_*_available`` returns ``false`` and calls to start updates emit :ref:`altimeter_failed<class_CMAltimeter_signal_altimeter_failed>`.

See Apple's `CMAltimeter reference <https://developer.apple.com/documentation/coremotion/cmaltimeter>`__.
