CMHeadphoneMotionManager
========================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Streams fused head motion data from AirPods Pro / AirPods Max / AirPods 3rd gen and later.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMHeadphoneMotionManager``. Provides :ref:`CMDeviceMotion<class_CMDeviceMotion>` samples representing head pose when compatible headphones are connected. Useful for head-tracked audio, spatial UI, or letting the user look around with their head while their hands are free.

\ **Requires the ``NSMotionUsageDescription`` Info.plist key (and on macOS, the matching entitlement).**\ 

\ **Platform availability:** Real implementation on **iOS 14+** and **macOS 14+**. On other platforms :ref:`is_device_motion_available<class_CMHeadphoneMotionManager_property_is_device_motion_available>` is ``false`` and :ref:`start_device_motion_updates()<class_CMHeadphoneMotionManager_method_start_device_motion_updates>` emits :ref:`update_failed<class_CMHeadphoneMotionManager_signal_update_failed>`.

See Apple's `CMHeadphoneMotionManager reference <https://developer.apple.com/documentation/coremotion/cmheadphonemotionmanager>`__.
