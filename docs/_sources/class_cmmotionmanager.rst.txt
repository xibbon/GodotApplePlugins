CMMotionManager
===============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Streams accelerometer, gyroscope, magnetometer, and fused device-motion data from the device.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMMotionManager``. Configure an update interval, call one of the ``start_*_updates`` methods, and connect to the matching signal to receive samples.

Prefer :ref:`device_motion_updated<class_CMMotionManager_signal_device_motion_updated>` over raw :ref:`accelerometer_updated<class_CMMotionManager_signal_accelerometer_updated>` / :ref:`gyro_updated<class_CMMotionManager_signal_gyro_updated>` / :ref:`magnetometer_updated<class_CMMotionManager_signal_magnetometer_updated>` when you need gravity-separated user acceleration, bias-corrected rotation, or device attitude.

\ **Platform availability:** Real implementation on **iOS**. On other platforms the manager exists but ``is_*_available`` returns ``false`` and calling ``start_*_updates`` emits :ref:`update_failed<class_CMMotionManager_signal_update_failed>`.

See Apple's `CMMotionManager reference <https://developer.apple.com/documentation/coremotion/cmmotionmanager>`__.

|void| **start_device_motion_updates**\ (\ referenceFrame\: :ref:`AttitudeReferenceFrame<enum_CMMotionManager_AttitudeReferenceFrame>`\ ) :ref:`🔗<class_CMMotionManager_method_start_device_motion_updates>`

Begins delivering fused :ref:`CMDeviceMotion<class_CMDeviceMotion>` samples via :ref:`device_motion_updated<class_CMMotionManager_signal_device_motion_updated>`. ``referenceFrame`` selects how attitude is referenced.
