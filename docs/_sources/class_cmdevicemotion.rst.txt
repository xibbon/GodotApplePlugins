CMDeviceMotion
==============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Fused sensor data combining accelerometer, gyroscope and magnetometer into attitude, gravity, user acceleration and bias-corrected rotation rate.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMDeviceMotion``. Use this instead of raw accelerometer/gyro data when you need device attitude, gravity-separated user acceleration, or bias-corrected rotation. Emitted by both :ref:`CMMotionManager<class_CMMotionManager>` (handheld device) and :ref:`CMHeadphoneMotionManager<class_CMHeadphoneMotionManager>` (AirPods).

See Apple's `CMDeviceMotion reference <https://developer.apple.com/documentation/coremotion/cmdevicemotion>`__.
