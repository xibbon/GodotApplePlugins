Godot Apple Plugins
===================

Overview
--------

Integrate Apple frameworks into your Godot games with GDScript. Add Game Center achievements and multiplayer, manage in-app purchases with StoreKit, build augmented reality experiences with ARKit, and connect to native authentication, motion, audio, and storage APIs.

Start with an integration guide, then explore the classes in each framework.
