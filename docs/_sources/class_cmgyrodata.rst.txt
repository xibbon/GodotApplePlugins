CMGyroData
==========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A single gyroscope sample produced by :ref:`CMMotionManager<class_CMMotionManager>`.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMGyroData``. Provides the raw rotation rate around each device axis. See Apple's `CMGyroData reference <https://developer.apple.com/documentation/coremotion/cmgyrodata>`__.
