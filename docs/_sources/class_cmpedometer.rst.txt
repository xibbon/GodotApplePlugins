CMPedometer
===========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Step, distance, and floor counts from the system pedometer.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMPedometer``. Supports both historical queries (already-recorded data from the system) and live updates.

\ **Requires the ``NSMotionUsageDescription`` Info.plist key.** On iOS the system records pedometer data continuously while motion permission is granted, so :ref:`query_pedometer_data()<class_CMPedometer_method_query_pedometer_data>` can return data even from before your app launched.

\ **Platform availability:** Real implementation on **iOS**. On other platforms the ``is_*_available`` static methods return ``false`` and calls report unavailability through their callback or :ref:`pedometer_failed<class_CMPedometer_signal_pedometer_failed>`.

See Apple's `CMPedometer reference <https://developer.apple.com/documentation/coremotion/cmpedometer>`__.
