CMMotionActivity
================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A user-activity classification (walking, running, automotive, etc.) from the system motion coprocessor.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMMotionActivity``. More than one activity flag may be set simultaneously (e.g. :ref:`walking<class_CMMotionActivity_property_walking>` and :ref:`automotive<class_CMMotionActivity_property_automotive>` when the user is moving inside a vehicle). The system uses :ref:`confidence<class_CMMotionActivity_property_confidence>` to indicate how certain the classification is.

See Apple's `CMMotionActivity reference <https://developer.apple.com/documentation/coremotion/cmmotionactivity>`__.
