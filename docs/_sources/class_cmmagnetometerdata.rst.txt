CMMagnetometerData
==================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A single magnetometer sample produced by :ref:`CMMotionManager<class_CMMotionManager>`.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMMagnetometerData``. Provides the raw magnetic field reading in microteslas along each device axis. Includes bias from device magnetic interference. For a bias-corrected value, use device-motion updates and read :ref:`CMDeviceMotion.magnetic_field<class_CMDeviceMotion_property_magnetic_field>` instead. See Apple's `CMMagnetometerData reference <https://developer.apple.com/documentation/coremotion/cmmagnetometerdata>`__.
