CMPedometerData
===============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Aggregated pedometer data covering a time window.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMPedometerData``. Optional Apple values (distance, floor counts, pace, cadence) report ``-1`` when the underlying capability is unavailable on the device. See Apple's `CMPedometerData reference <https://developer.apple.com/documentation/coremotion/cmpedometerdata>`__.
