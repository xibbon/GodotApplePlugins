CMAltitudeData
==============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A relative altitude / barometric pressure sample from :ref:`CMAltimeter<class_CMAltimeter>`.

.. rst-class:: classref-introduction-group

Description
-----------

Wraps Apple's ``CMAltitudeData``. The altitude is reported relative to the point at which updates were started, not absolute sea level — for absolute readings, use :ref:`CMAltimeter.start_absolute_altitude_updates()<class_CMAltimeter_method_start_absolute_altitude_updates>` and :ref:`CMAbsoluteAltitudeData<class_CMAbsoluteAltitudeData>`.

See Apple's `CMAltitudeData reference <https://developer.apple.com/documentation/coremotion/cmaltitudedata>`__.
