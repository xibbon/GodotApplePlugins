GKGameCenterViewController
==========================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Presents Game Center dashboards and player information.

.. rst-class:: classref-introduction-group

Description
-----------

Call a static ``show_*`` method to present Game Center UI. Call :ref:`dismiss()<class_GKGameCenterViewController_method_dismiss>` to close the UI shown by the last ``show_*`` call.


.. tabs::

 .. code-tab:: gdscript

    GKGameCenterViewController.show_type(GKGameCenterViewController.DASHBOARD)



Later, from your own event handler, call:


.. tabs::

 .. code-tab:: gdscript

    GKGameCenterViewController.dismiss()
