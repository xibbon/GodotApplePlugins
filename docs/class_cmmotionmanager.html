CMMotionManager¶

Inherits: RefCounted < Object

Streams accelerometer, gyroscope, magnetometer, and fused device-motion data from the device.

Description¶

Wraps Apple’s CMMotionManager. Configure an update interval, call one of the start_*_updates methods, and connect to the matching signal to receive samples.

Prefer device_motion_updated over raw accelerometer_updated / gyro_updated / magnetometer_updated when you need gravity-separated user acceleration, bias-corrected rotation, or device attitude.

Platform availability: Real implementation on iOS. On other platforms the manager exists but is_*_available returns false and calling start_*_updates emits update_failed.

See Apple’s CMMotionManager reference.

Enumerations¶

enum AttitudeReferenceFrame: 🔗

AttitudeReferenceFrame XARBITRARY_Z_VERTICAL = 1

Z axis vertical, X axis aligned with an arbitrary direction in the horizontal plane.

AttitudeReferenceFrame XARBITRARY_CORRECTED_Z_VERTICAL = 2

Same as XARBITRARY_Z_VERTICAL but corrected for magnetometer drift.

AttitudeReferenceFrame XMAGNETIC_NORTH_Z_VERTICAL = 4

Z axis vertical, X axis pointing toward magnetic north. Requires the magnetometer.

AttitudeReferenceFrame XTRUE_NORTH_Z_VERTICAL = 8

Z axis vertical, X axis pointing toward true north. Requires the magnetometer and Location Services.

Method Descriptions¶

void start_accelerometer_updates() 🔗

Begins delivering accelerometer samples via accelerometer_updated. Sampling cadence is controlled by accelerometer_update_interval.

void start_device_motion_updates(referenceFrame: AttitudeReferenceFrame) 🔗

Begins delivering fused CMDeviceMotion samples via device_motion_updated. referenceFrame selects how attitude is referenced. Pass XMAGNETIC_NORTH_Z_VERTICAL or XTRUE_NORTH_Z_VERTICAL to align yaw with magnetic or true north (requires the magnetometer).

void start_gyro_updates() 🔗

Begins delivering gyroscope samples via gyro_updated. Sampling cadence is controlled by gyro_update_interval.

void start_magnetometer_updates() 🔗

Begins delivering magnetometer samples via magnetometer_updated. Sampling cadence is controlled by magnetometer_update_interval.

void stop_accelerometer_updates() 🔗

Stops accelerometer updates.

void stop_device_motion_updates() 🔗

Stops device-motion updates.

void stop_gyro_updates() 🔗

void stop_magnetometer_updates() 🔗
